## Pick an aesthetic

An aesthetic is a complete look: Once UI theme, fonts, page background and home page layout. Magic Portfolio ships five: Classic, Editorial, Swiss, Aurora and Terminal. Choose one with a single line.

<CodeBlock
    marginBottom="16"
    codes={[
  {
    code:
`// classic | editorial | swiss | aurora | terminal
const aesthetic: AestheticName = "editorial";`,
    language: "tsx",
    label: "src/resources/once-ui.config.ts",
    highlight: "2"
  }
]} />

The demo shows a picker that lets visitors try every aesthetic. Turn it off on your own site with `aestheticSwitcher: false` in the `display` object.

## Fine-tune the theme

Anything in `styleOverrides` wins over the aesthetic's own choices. You can generate a custom color palette on [Once UI](https://once-ui.com/customize).

<CodeBlock
    marginBottom="16"
    codes={[
  {
    code:
`const styleOverrides: Partial<StyleConfig> = {
  theme: "system", // dark | light | system
  brand: "cyan", // blue | indigo | violet | magenta | pink | red | orange | yellow | moss | green | emerald | aqua | cyan
  border: "rounded", // rounded | playful | conservative | sharp
};`,
    language: "tsx",
    label: "src/resources/once-ui.config.ts"
  }
]} />

## Rearrange the home page

The home page is built from sections, and each aesthetic has its own list. Set `homeSections` to reorder, remove or swap them.

<CodeBlock
    marginBottom="16"
    codes={[
  {
    code:
`const homeSections: HomeSection[] = [
  { type: "hero", variant: "split" }, // centered | statement | split | terminal
  { type: "ticker" },
  { type: "work", variant: "bento" }, // stack | index | bento
  { type: "posts", variant: "list", range: [1, 4] }, // grid | list
  { type: "newsletter" },
];`,
    language: "tsx",
    label: "src/resources/once-ui.config.ts"
  }
]} />

## Make your own aesthetic

Copy a preset in `src/resources/aesthetics.ts` and change it: colors and shapes in `style`, fonts from `src/resources/fonts.ts`, the page `background` (gradient, dots, grid, lines, plus blobs or particles) and the `home` sections. Add it to the `aesthetics` object and it shows up in the picker too.

Want a WebGL background? [Once UI Pro effects](https://once-ui.com/effects) such as Silk and Prism Glow drop into `src/components/aesthetic/ProEffect.tsx`.
