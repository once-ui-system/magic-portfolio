## Meta tags

Magic Portfolio automatically generates meta- and open graph tags for your pages based on the `content.js` file.

## Schema

Magic Portfolio automatically generates schema tags for your pages based on the `content.js` file.

## Open Graph image

## AI assistants

Magic Portfolio serves `/llms.txt`, a plain-text guide to your site for AI assistants, and `/llms-full.txt` with the full text of your posts and projects. Both are built from your content, and password-protected or switched-off pages are left out. `robots.txt` lets AI search bots in, since they answer questions and link back to you, and keeps AI training bots out. Change any of this in the `seo` object:

<CodeBlock
    marginBottom="16"
    codes={[
      {
        code:
`const seo: SeoConfig = {
  llmsTxt: {
    enabled: true, // false: /llms.txt and /llms-full.txt return 404
    fullText: true, // false: only /llms-full.txt returns 404
  },
  aiCrawlers: {
    search: true, // let AI search bots in
    training: false, // keep AI training bots out
    searchBots: [...aiSearchBots, "YouBot"], // add or remove user agents
    trainingBots: aiTrainingBots,
  },
};`,
        language: "tsx",
        label: "src/resources/once-ui.config.ts"
      }
    ]}
/>

The default bot lists live in `src/resources/aiCrawlers.ts`. Leave `searchBots` or `trainingBots` out to use them as they are.
