## Por que usar o SDK?

O [Kadena Snap SDK](https://github.com/kadena-community/kadena-snap) fornece ferramentas modernas para construir dApps seguros e integrados ao Snap usando:

- 🧱 `create-kadena-app`: CLI para estruturar aplicativos Next.js
- 🔌 `@kadena/wallet-adapter-snap`: Wallet adapter plug-and-play para o MetaMask Snap
- ⚙️ Interfaces totalmente tipadas e extensibilidade

## Passo 1: Estruture Seu Projeto

Comece gerando um novo dApp usando a CLI:

```bash
npx @kadena/create-kadena-app generate-project -t nextjs -n my-kadena-dapp
cd my-kadena-dapp
```

Instale as dependências:

```bash
pnpm install
# ou npm install / yarn install
```

## Passo 2: Adicione o Snap Wallet Adapter

Na entrada do seu aplicativo (`pages/_app.tsx` ou similar):

```ts
import { snapAdapter } from '@kadena/wallet-adapter-snap';
import { AdapterFactory } from '@kadena/wallet-adapter-base';

const adapters: AdapterFactory[] = [
  snapAdapter(),
];
```

Isso permite que seu aplicativo se conecte com a MetaMask e acesse as funcionalidades do Kadena Snap usando uma interface de carteira comum.

## Passo 3: Conecte a Carteira na Interface

Use a API do wallet adapter nos seus componentes para conectar e assinar transações:

```ts
import { useWalletConnect } from '@kadena/wallet-adapter-react';

const { connect, disconnect, isConnected, connectedWallet } = useWalletConnect();

return (
  <button onClick={() => connect()}>Conectar Carteira</button>
);
```

Uma vez conectado, você poderá chamar `sign`, `quicksign` e muito mais — tudo através da abstração do adapter.

## Passo 4: Inicie o Servidor de Desenvolvimento

```bash
pnpm dev
# ou npm run dev / yarn dev
```

Abra [http://localhost:3000](http://localhost:3000) — seu dApp habilitado para o Snap está rodando agora.
