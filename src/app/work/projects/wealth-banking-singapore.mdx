# Retail banking & wealth banking - Singapore

A large-scale financial application handling millions of downloads, focusing on dashboard insights, and banking & earning functionalities.

## Key Contributions
- **High Impact:** Contributed to a major banking app (1M+ downloads) serving users across Singapore and Indonesia.
- **Modernization:** Implemented Jetpack components (ViewModel, Dagger Hilt, and Coroutines) replacing legacy RxJava patterns to modernize the codebase.
- **Migration:** Led the Java to Kotlin migration for the Bank & Earn module and implemented multi-module architecture with MVVM, improving code maintainability.
- **Performance:** Delivered a measurable performance improvement by reducing screen load time from 11 seconds to 7 seconds for a key user flow.

## Technology Stack
- Kotlin, Java
- MVVM, Multi-module Architecture
- Dagger Hilt
- Coroutines
- RxJava (Legacy)
