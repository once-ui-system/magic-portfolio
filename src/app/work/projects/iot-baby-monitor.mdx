# Smart Home IoT Baby Monitor

This project focused on delivering a reliable and high-performance video streaming application integrated with smart home IoT devices. It was designed to provide real-time audio and video feeds along with sensor data from a baby's room.

## Key Contributions
- **Video Streaming:** Engineered the core video streaming capabilities using Exo Player, ensuring low-latency and high-quality live feeds.
- **IoT Integration:** Developed robust communication protocols for Android to interface with IoT devices via BLE (Bluetooth Low Energy) and Wi-Fi.
- **Sensor Data:** Integrated real-time room temperature and humidity sensor data overlays directly onto the video feed.
- **Architecture:** Built from scratch using modern MVVM architecture patterns and Jetpack components to ensure scalability and maintainability.
- **End-to-End Delivery:** Single-handedly developed the app from scratch and successfully released it into production.

## Technology Stack
- Android, Java
- MVVM Architecture
- Exo Player (Video Streaming)
- BLE / Bluetooth, Wi-Fi SDKs
- Firebase Analytics & Authentication
