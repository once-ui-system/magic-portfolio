# Smart Wi-Fi Doorbell & Video Streaming

This project for Swann Buzz focused on delivering a reliable and high-performance video streaming application integrated with smart home IoT Wi-Fi doorbells. It was designed to provide real-time audio and video feeds along with two-way communication capabilities for home security.

## Key Contributions
- **Video Streaming:** Engineered the core video streaming capabilities, ensuring low-latency and high-quality live feeds from the doorbell camera.
- **IoT Integration:** Developed robust communication protocols for Android to interface with IoT devices via Wi-Fi and Bluetooth.
- **Two-Way Audio:** Integrated real-time audio communication overlays directly onto the video feed to interact with visitors.
- **Performance:** Optimized application performance and device communication reliability.
- **End-to-End Delivery:** Single-handedly developed and scaled the app, ensuring a smooth production release.

## Technology Stack
- Android, Java
- Video Streaming Libraries
- Wi-Fi & Bluetooth SDKs
- IoT Device Communication
