## Overview

During my internship at NeuralMobi Ltd. (Jul 2025 - Oct 2025, remote) I developed the web administration interface of FanRadars with Vue.js. The admin is where the platform's operators manage users, content and settings, so the focus was on a robust permission model and a fast, secure interface.

## Key Features

- **Administration features**: integration and management of the platform's back-office functionality.
- **RBAC**: user rights and roles management, with UI and API access gated by permissions.
- **REST API integration**: efficient data loading and mutations against the backend REST APIs.
- **Performance & security**: admin-side optimizations and hardening.

## Technologies Used

- Vue.js
- REST APIs
- RBAC (roles and permissions)
