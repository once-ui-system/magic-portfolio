## Overview

Since 2023 I work as a freelance full-stack developer, mostly on learning platforms. Several of these LMS products run in production today, and I handle them end to end: requirements and specifications, architecture, development, deployment and maintenance.

## What these platforms include

- **Multi-tenant architecture**: one deployment serving several organisations with isolated data.
- **Billing**: subscription and payment flows with Stripe.
- **RBAC**: roles and permissions for admins, instructors and learners.
- **Analytics dashboards**: progress and engagement metrics for instructors and admins.
- **LMS integrations**: LTI for connecting with other learning tools where needed.

## Technologies Used

- Next.js, React, TypeScript
- Node.js (NestJS / Express)
- PostgreSQL, Supabase, Drizzle ORM
- Stripe, LTI, Docker
