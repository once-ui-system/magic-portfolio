# Retail banking app (Amsterdam, Netherlands)

This project involved developing and maintaining core modules for a major retail banking app built on the Backbase platform.

## Key Contributions
- **Core Modules:** Developed critical modules including Onboarding, Cards, Savings, and Insurance.
- **Architecture:** Architected features using Kotlin, MVVM, and Clean Architecture with KOIN for dependency injection. 
- **Modern Android:** Heavily utilized Jetpack components including ViewModel and Coroutines.
- **Stability:** Actively worked on crash rate reduction and ANR fixes, contributing to a smoother user experience at scale.

## Technology Stack
- Kotlin
- MVVM, Clean Architecture
- KOIN
- Jetpack Components (ViewModel, Coroutines)
- GitHub Copilot, Cursor
