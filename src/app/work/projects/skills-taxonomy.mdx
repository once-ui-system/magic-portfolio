## Overview

Developed a Python-based NLP model to structure 68K+ unstructured data points into a centralized skills taxonomy, improving resource allocation across a 10K-employee workforce while leading a 150+ person offsite with $250K budget management.

## Technical Achievement

### NLP Model Development
- Built Python-based NLP solution
- Processed 68K+ unstructured employee skill data points
- Created standardized skills taxonomy framework

## Business Impact

### Resource Allocation
- Improved allocation across 10K-employee workforce
- Enhanced ability to match talent to projects
- Identified skill gaps and training opportunities

## Outcomes

The centralized skills taxonomy enabled strategic resource allocation and provided leadership with comprehensive visibility into organizational capabilities and talent positioning.
