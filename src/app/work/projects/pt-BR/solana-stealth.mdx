## Visão Geral
O Solana Stealth traz privacidade para a blockchain de alta velocidade da Solana. Ao implementar um protocolo de endereço stealth, permitimos que os usuários recebam tokens sem vincular sua identidade pública à transação. Isso garante a privacidade financeira, mantendo a velocidade e o baixo custo da Solana.

## Principais Recursos
- **Endereços Stealth**:
  - O receptor gera um endereço único de uso único para cada transação.
  - O remetente criptografa os dados da transação, legíveis apenas pelo receptor.
  - Desacoplamento matemático das identidades do remetente e do receptor.

- **Alto Desempenho**:
  - Otimizado para o tempo de execução Sealevel da Solana.
  - Finalização de transação em menos de um segundo.
  - Uso mínimo do orçamento de computação para rendimento máximo.

- **Suporte a SPL Token**:
  - Compatibilidade total com tokens SPL (USDC, SOL, etc.).
  - Integração sem atrito com carteiras existentes.

## Tecnologias Utilizadas
- **Rust (Anchor Framework)**:
  - Lógica de contrato inteligente e gerenciamento de estado.
  - Arquitetura de programa segura e auditada.

- **TypeScript / React**:
  - Frontend amigável para gerar endereços stealth.
  - Integração de adaptador de carteira para assinatura perfeita.

- **Criptografia de Curva Elíptica**:
  - Operações de curva secp256k1 e ed25519 para derivação de endereços.
  - Troca de chaves Diffie-Hellman para geração de segredo compartilhado.

## Desafios e Aprendizados
1. **Limites de computação On-Chain**:
   - A criação de operações criptográficas eficientes dentro do orçamento de computação da Solana foi fundamental.
   - Utilizamos programas pré-compilados sempre que possível para descarregar matemática cara.

2. **Experiência do Usuário**:
   - Abstrair a complexidade do gerenciamento de chaves foi essencial para a adoção.
   - Construímos uma interface de usuário intuitiva que lida com o trabalho pesado da criptografia em segundo plano.

Este projeto ultrapassou os limites do que é possível para privacidade em L1s de alto desempenho.
